# مراقب شبكات العراق | Iraq Network Monitor

هذا المستودع العام مخصص لبناء نسخة Android من التطبيق باستخدام GitHub Actions. يبقى المستودع الأصلي الخاص هو مرجع التطوير الأساسي.

## البناء
- يبدأ البناء تلقائياً عند تحديث فرع `main` أو يدوياً من تبويب Actions.
- يستخدم GitHub-hosted Ubuntu runner القياسي.
- لا توجد خطوة نشر إلى الخادم؛ الناتج يُحفظ كـ Actions Artifact لمدة 14 يوماً.
- قبل إعداد مفتاح التوقيع، ينتج Debug APK لاختبار التجميع فقط.
- بعد إضافة أسرار التوقيع الأربعة، ينتج Release APK موقعاً بمفتاح ثابت.

## أسرار التوقيع المطلوبة
من Settings → Secrets and variables → Actions أضف:
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

**مهم:** احتفظ بنسخة آمنة من ملف keystore وكلمات مروره. يجب استخدام المفتاح نفسه في كل الإصدارات المستقبلية حتى تعمل التحديثات فوق النسخة المثبتة. لا ترفع ملف keystore أو كلمات المرور إلى المستودع.

لا تحذف التطبيق المثبت حالياً قبل التأكد من توقيع النسخة الجديدة وخطة التحديث؛ إلغاء التثبيت قد يمسح بيانات التطبيق المحلية.
