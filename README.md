# مراقب شبكات العراق | Iraq Network Monitor

هذا المستودع العام هو المسار النشط والمرجع الحالي لمصدر التطبيق وعمليات CI والبناء والنشر. تُجرى التغييرات عبر فروع وطلبات دمج (Pull Requests)، ولا يُعد أي بناء اختباري نسخة رسمية.

## البناء والتحقق

- يستخدم المشروع Flutter 3.50.0 المثبّت على commit رسمي محدد، مع Java 17.
- كل Pull Request يمر بتحليل Flutter والاختبارات؛ وتُبنى نسخة Android غير موقعة لاختبار تغييرات التطبيق عند الحاجة.
- النشر الإنتاجي الموقّع يعمل فقط من المسار الموثوق على الفرع `main` بعد اجتياز بوابة الإصدار.
- نجاح CI لطلب دمج لا يعني إنشاء APK إنتاجي أو نشره.

## الإصدارات الرسمية

- رقم الحزمة: `com.example.abrj_iraq`.
- ملف APK المباشر: [آخر إصدار رسمي](https://mahmoudaljuorany.store/iraq-network-monitor-1.0.29-32.apk).
- قناة التحديث الخاصة بالتطبيق: [version.json](https://mahmoudaljuorany.store/updates/iraq-network-monitor/version.json).
- سجل التغييرات المنشور: [changelog.json](https://mahmoudaljuorany.store/updates/iraq-network-monitor/changelog.json).

## أمان التوقيع والتحديث

- يجب الحفاظ على شهادة توقيع Android الحالية ومفتاح توقيع بيان OTA؛ فهما مفتاحان منفصلان.
- لا تُنشئ مفاتيح بديلة ولا ترفع ملفات keystore أو كلمات المرور أو مفاتيح OTA الخاصة أو رموز الوصول إلى المستودع.
- يتحقق التطبيق من توقيع Ed25519 وبصمة SHA-256 وهوية شهادة APK قبل قبول التحديث.
- لا تحذف النسخة المثبتة بغرض التحديث؛ استخدم آلية التحديث داخل التطبيق حتى تبقى بياناته المحلية.

## سياسة التغيير والإصدار

1. أنشئ فرعاً من `main` لكل ميزة أو إصلاح.
2. أضف اختبارات تغطي السلوك الجديد والحالات الحدّية.
3. حدّث رقم الإصدار وملاحظات العربية والإنجليزية وسجل التغييرات عند تجهيز إصدار تطبيق جديد.
4. ادمج التغيير بعد نجاح CI والمراجعة.
5. لا تعلن عن نسخة رسمية إلا بعد نجاح مسار التوقيع والنشر والتحقق من الملفات المنشورة.
